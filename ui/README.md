# F1 Replay UI

This is the frontend for the F1 Replay application, built with React and Vite.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

## Key Components

- **TrackMap**: Visualizes the circuit and car position.
- **TelemetryHUD**: Displays live car telemetry (Speed, RPM, Gear, etc.).

## Tech Stack
- React
- Vite
- Axios
- Lucide React (Icons)
